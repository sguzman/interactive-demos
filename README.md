# interactive-demos

A permanent public playground for small interactive browser demos made during ChatGPT sessions.

## Convention

- One repository, many demos.
- Each demo lives in its own top-level folder, e.g. `watch/`, `rocket/`, `turbine/`.
- The root `index.html` is a gallery linking to the demos.
- Prefer self-contained static HTML/CSS/JS when practical.
- Do **not** create a new repository for each experiment.

## Current demos

- `watch/` — semi-realistic Three.js exploded mechanical wristwatch anatomy viewer.
