DOCUMENTATION · PROVENANCE · M5G

ETA / Unitas 6497-2

M5g couples the reconstructed escapement contact path directly to the integrated balance. A center crossing is now only an impulse opportunity: the M5d tooth/pallet geometry must admit a coherent impulse interval before M5f is allowed to add Δω to the balance.

Accuracy contract.

The official reference remains 3 Hz / 21,600 A/h. M5g improves causal structure, but the pallet faces, contact clearances, impulse envelope, damping, impulse gain and oscillator constants remain educational reconstruction parameters rather than ETA factory geometry or measured dynamics.

Foundation retained

M3 established the reference-derived train and its pitch/stack diagnostics. M4 added causal winding, setting and reserve. M5a–M5d made Swiss-lever release event-resolved and then geometry-constrained. M5e exposed amplitude-dependent rate. M5f replaced the assigned phase clock with an integrated oscillator carrying explicit balance angle θ and angular velocity ω.

M5g — geometry decides whether impulse exists

M5f still had one shortcut: a usable center crossing plus reserve and a healthy solver automatically received an angular-velocity kick.

M5g removes that shortcut. The center crossing now asks the calibrated M5d contact path whether an impulse interval actually exists for the corresponding alternating entry/exit pallet transition.

crown → reserve → drive proxy → center crossing → pallet/tooth impulse-path gate → Δω → integrated θ/ω → contact-constrained escape release → train → hands

The same reconstructed escapement topology can now veto both escape-wheel motion and energy transfer into the balance.

Admission test

For every detailed center crossing, M5g samples the reconstructed pallet/tooth path across the unlock and impulse region. An impulse is admitted only if:

  • the starting face clears the M5d unlock threshold;
  • the geometry-derived half-tooth release spans a real impulse interval;
  • the tracked tooth remains inside the reconstruction-level contact envelope;
  • the M5d penetration guard can keep the path non-penetrating;
  • the contact solution remains finite and coherent.

If the path fails any test, the M5f balance receives no Δω for that crossing.

The nominal tooth/face contact tolerance remains 0.035 mm. M5g derives a wider diagnostic admission envelope from that reconstruction tolerance so the gate tests the coherence of a path rather than pretending a single idealized point is a manufacturing contact patch.

Live M5g diagnostics

The new Impulse contact gate · M5g panel reports gate decision, pallet transition, nearest sampled tooth/face gap, release span, impulse-path sample count, explicit reason for admission or denial, and accepted/denied geometry probes.

An optional marker shows the tracked tooth and nearest reconstructed face point. Green indicates an admitted path; red indicates a denied path.

M5f oscillator remains physical-state driven

The balance still evolves as explicit θ/ω state under a normalized restoring term and damping term. Impulse remains an angular-velocity increment rather than a direct amplitude assignment. The phase portrait, effective frequency, rate error and phase-drift diagnostics remain active.

The current reconstruction uses approximately 0.006 damping ratio, 0.42 rad/s maximum normalized impulse kick before drive/saturation scaling, 0.18 normalized unlock amplitude, 1.2% restart reserve and a 0.34 restart-amplitude seed. These are simulation parameters, not ETA measurements.

Fast-forward behavior

At ordinary speeds every center crossing runs the detailed M5g geometry admission test. At very large diagnostic time scales, M5f still uses its explicit fast-forward envelope approximation. M5g probes both alternating pallet parities and uses the admitted fraction to scale average impulse replenishment, avoiding thousands of contact solves per browser frame.

Why M5g matters

Before this pass, geometry controlled how far the escape wheel could move, but energy transfer into the oscillator was still admitted one abstraction earlier. M5g closes that mismatch: bad contact geometry can now deny the impulse itself.

This still is not rigid-body physics, but the mechanism is less like separately choreographed animation and more like a single causal loop.

What M5g still does not claim

  • exact ETA escape-tooth or pallet-jewel polygons;
  • measured lock, draw, drop or impulse-face geometry;
  • rigid-body collision manifolds;
  • friction, lubrication, elastic impact or rebound;
  • actual pallet efficiency or calibrated impulse work;
  • measured balance inertia, hairspring stiffness or physical amplitude;
  • factory timing performance.

Inspection workflow

Wind the watch, choose Escapement, assemble the movement, enable both the M5d solver overlay and the M5g impulse marker, then run at 0.1× or 0.25×. Watch the gate decision together with θ, ω, Δω, the contact gap and geometry-derived escape release.
