DOCUMENTATION · PROVENANCE · M5E

ETA / Unitas 6497-2

M5e separates reserve-consuming runtime from oscillator phase time. Dynamic balance amplitude now perturbs simulated rate, so a weak oscillator can lose time before it becomes too weak to unlock the escapement.

Accuracy contract.

The official reference remains 3 Hz / 21,600 A/h. The new amplitude→rate curve is an explicit educational isochronism model, not measured ETA 6497-2 timing data. Nominal specification and simulated instantaneous rate are shown separately.

What the earlier milestones already established

M3 built the reference-derived train topology, pitch geometry, axial planes, staffs and bearing diagnostics. M4 made winding, hand setting and reserve stateful. M5a–M5c made the Swiss lever release event-driven, added pallet/safety geometry, and gave the balance a reserve-dependent normalized amplitude that can decay into a low-amplitude stall. M5d then moved each half-tooth release toward reconstructed spatial contact using pallet-face travel and tooth-to-segment clearance.

M5e — two clocks

The model now tracks two distinct time quantities:

  • Reserve-consuming runtime — the simulated seconds paid for by stored mainspring reserve.
  • Oscillator phase time — the clock used for balance center crossings, pallet motion and escapement events.

Before M5e those clocks advanced together. M5e allows oscillator phase to run slightly fast or slow relative to reserve-consuming runtime. The watch can therefore consume one hour of modeled reserve while indicating a slightly different amount of elapsed time.

Low-amplitude endpoint−120 s/day
High-amplitude endpoint+12 s/day
Unlock threshold0.18 normalized
Nominal spec3 Hz / 21,600 A/h

Below the reference zone, progressively lower normalized amplitude is modeled as increasingly slow. Above the reference zone, unusually high amplitude can run slightly fast. The curve is smooth and intentionally visible enough to teach the dependency.

These endpoint values and the 0.74 reference amplitude are reconstruction parameters. They are not factory timing curves or measured 6497-2 performance.

Rate multiplier

The model converts the current seconds/day error into a phase multiplier:

rate multiplier = 1 + (seconds/day error ÷ 86,400)

Reserve consumption continues on runtime. The oscillator advances on runtime multiplied by this rate factor. That distinction is what lets rate error accumulate without pretending the spring itself gained or lost reserve.

Rate error now propagates into the mechanism

The adjusted oscillator phase drives the same geometry-constrained escapement from M5d. Therefore the rate error is not a disconnected number in a dashboard. It propagates through:

  • balance center crossings;
  • pallet motion;
  • entry/exit contact clearance;
  • geometry-constrained half-tooth release;
  • fourth/seconds wheel motion;
  • third and centre wheels;
  • small seconds, minute and hour hands.

Accumulated phase drift

The live panel reports oscillator phase drift as oscillator phase time minus reserve-consuming runtime. A negative value means the model has lost time against nominal runtime; a positive value means it has gained.

This separates an instantaneous rate such as −40 s/day from the accumulated consequence of having run at that error for some duration.

Effective frequency and A/h

M5e reports a live effective frequency and effective alternations-per-hour value in addition to the fixed nominal ETA reference. When the watch is stopped, effective frequency is displayed as zero instead of implying that a stationary balance is still oscillating at 3 Hz.

Live isochronism plot

A small curve in the control panel plots normalized balance amplitude against the current educational seconds/day model. A moving point shows the oscillator's present state. As reserve weakens and amplitude falls, the point moves down the modeled low-amplitude side before the M5c unlock threshold eventually stops the watch.

Diagnostic exaggeration

The rate-model strength control provides:

  • 0× — nominal phase speed; amplitude-rate coupling disabled;
  • 1× — educational model;
  • 5× — diagnostic exaggeration;
  • 20× — extreme inspection.

Only the assumed rate error is magnified. Stored reserve, M5c damping/impulse dynamics and M5d contact geometry are not multiplied. The high settings exist so timing drift is visible without waiting for hours.

M5d contact solver retained

The visible escapement still uses the 15-tooth wheel with a 24° tooth pitch and 12° half-tooth release. Current reconstructed spatial targets remain 0.030 mm unlock travel, 0.040 mm capture distance, 0.035 mm nominal contact tolerance and a 0.006 mm penetration guard. These are reconstruction targets rather than ETA production tolerances.

Current causal chain

crown → reserve → drive proxy → impulse → balance amplitude → amplitude-dependent phase speed → pallet/contact geometry → escape release → train → hands

M5e closes the conceptual gap between “amplitude changes” and “timekeeping changes,” while still making the assumed isochronism law explicit.

What M5e still does not claim

  • measured ETA rate-vs-amplitude data or physical balance amplitude in degrees;
  • ETA balance inertia, hairspring stiffness or a calibrated restoring-force law;
  • real regulator-pin geometry, beat error or poise error;
  • position-dependent timing, temperature effects or shock response;
  • real barrel-torque-to-rate calibration;
  • escapement friction/lubrication influence on rate;
  • factory adjustment grades or production timing tolerances.

Inspection workflow

For normal use, leave Rate-model strength at 1×. To make M5e obvious quickly, wind the watch, use the Escapement view, run at 300× or 3600×, and switch the rate model to 5× or 20×. Watch balance amplitude, seconds/day error and phase drift together. Return to 0.1× / 0.25× and the M5d contact overlay for detailed escapement inspection.

Next work

M5f — state-integrated oscillator

Represent balance phase and angular velocity as explicit state, add a normalized hairspring restoring term, inject escapement impulse into velocity/energy, and let timing emerge from the integrated oscillator rather than directly assigning phase speed from a curve.

M5g — deeper polygonal contact

Replace tooth-tip/face-segment distance with reconstructed tooth and pallet polygons, derive lock/drop from those surfaces, and include roller-jewel/fork-slot safety tests in the same framework.

M6 — shared system simulation

Separate barrel-arbor winding from barrel-drum release, improve train force transmission, and consolidate reserve, impulse, oscillator and escapement state into one system model.
