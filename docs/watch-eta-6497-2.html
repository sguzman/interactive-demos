DOCUMENTATION · PROVENANCE · M5I

ETA / Unitas 6497-2

M5i turns polygon-admitted escapement contact into variable impulse work. Remaining spring drive supplies an available work budget; M5h finite-surface following and contact quality determine what portion is delivered to the balance, and the M5f angular-velocity kick is continuously scaled from that transferred fraction.

Accuracy contract.

The official reference remains 3 Hz / 21,600 A/h. M5i work values are normalized educational units, not joules. Its path normalization, contact-quality law, transfer efficiency and Δω mapping are reconstruction parameters rather than measured ETA torque, pallet efficiency or balance inertia.

Foundation retained

M3 established the reference-derived train and pitch/stack diagnostics. M4 added stateful winding, setting and reserve. M5a–M5d made Swiss-lever release event-resolved and geometry-constrained. M5e exposed amplitude-dependent rate. M5f integrated balance angle θ and angular velocity ω. M5g made geometry admit or deny impulse. M5h replaced point/line contact with finite escape-tooth and pallet-jewel polygons that govern lock, impulse following, drop, capture, release and admission.

M5i — from permission to work transfer

Before M5i, once M5h admitted an impulse, the M5f kick was still effectively fixed after reserve and amplitude saturation. M5i removes that last binary energy-transfer assumption.

crown → reserve → drive proxy → tooth/jewel polygon path → available work → delivered / lost work → scaled Δω → integrated θ/ω → polygon-constrained release → train → hands

The finite contact path now affects both whether impulse exists and how much normalized impulse reaches the oscillator.

Available train work

The current reserve-derived drive proxy supplies a normalized 0–1 work budget for each center-crossing opportunity. The UI labels this quantity in work units. One work unit is not one joule; it is simply the full current normalized drive budget.

Surface-follow distance

M5i samples the M5h polygon solver across each alternating entry→exit or exit→entry beat. It accumulates only positive escape-wheel travel still classified as IMPULSE · POLYGON SURFACE.

That angular travel is converted to path length at the reconstructed 2.25 mm tooth-tip radius. The normalization currently treats 40% of the full 12° half-tooth tip arc as complete reference path coverage. That 40% value is an educational choice, not an ETA impulse-duration measurement.

Contact quality

The signed M5h polygon gap becomes a second transfer factor. Close, non-penetrating surfaces score highly. A widening positive gap reduces quality toward zero at the 0.080 mm impulse envelope; overlap also reduces quality as it approaches the M5h maximum accepted penetration.

The current gap response uses an exponent of 1.35. This is not a measured friction or efficiency law.

Transfer efficiency and work split

transfer efficiency ≈ path coverage × contact quality

Both factors are normalized. A polygon path already rejected by M5h has zero transfer efficiency.

The work budget is then split as:

delivered work = available work × transfer efficiency

rejected/lost work = available work − delivered work

“Lost” is broad bookkeeping. The model does not yet distinguish friction, oil-film shear, impact, deformation, train friction, recoil or sound as separate physical loss channels.

Delivered work scales Δω

M5f still actuates the balance with an angular-velocity increment. M5i extends the impulse-admission interface so geometry may return a continuous scale as well as an admitted/denied result.

The current mapping is:

Δω scale ≈ √(transfer efficiency)

The square root keeps the normalized work bookkeeping energy-like without claiming a calibrated balance inertia.

The resulting kick still contains M5f's reserve-derived drive term and amplitude saturation, but two admitted contacts with different polygon work paths can now deliver different Δω.

Fast-forward behavior

At detailed speeds every center crossing gets its own M5i work estimate. At very large diagnostic time scales M5f retains its explicit fast-forward envelope approximation. That approximation now uses the mean continuous impulse scale of representative alternating polygon paths instead of only the fraction of binary admitted paths.

Live M5i diagnostics

The Impulse work transfer · M5i panel reports:

  • available train work;
  • delivered work;
  • rejected/lost work;
  • surface-follow distance in mm;
  • contact quality;
  • total transfer efficiency;
  • resulting Δω packet scale;
  • explicit work-transfer verdict.

The M5h polygon solver panel and tooth/jewel overlay remain available at the same time, so the work result can be inspected against the actual finite surfaces that produced it.

What M5i improves

Before: valid contact → fixed admitted impulse packet.

After: valid contact → measure polygon following → estimate transfer efficiency → split available work into delivered/lost work → continuously scale the balance impulse.

What M5i still does not claim

  • work in joules;
  • measured ETA barrel or escape-wheel torque;
  • force vectors integrated over the tooth/pallet contact surface;
  • real pallet sliding friction or lubrication losses;
  • measured pallet efficiency;
  • elastic impact, rebound, deformation or contact stress;
  • calibrated balance inertia or hairspring elastic energy;
  • train inertia, tooth friction or production timing performance.

Inspection workflow

Wind the watch, choose Escapement, assemble it, enable Show M5h tooth / jewel polygons, and run at 0.1× or 0.25×. Compare surface-follow distance, contact quality, transfer efficiency and delivered work with the M5f θ/ω state, phase portrait and Last impulse Δω readout.
