ETA / Unitas 6497-2

M6a starts the shared-system mechanics phase by separating barrel-arbor winding from barrel-drum release. Stored spring twist now produces normalized torque; explicit train load and transmission loss reduce that torque before M5i receives its escapement work budget.

Accuracy contract.

The official reference remains 3 Hz / 21,600 A/h with 53 h minimum / 60 h typical reserve. M6a's drum turns, torque curve, train load, transmission efficiency, and work values are educational reconstruction parameters—not ETA torque measurements or manufacturing data.

Current causal chain

crown → barrel arbor winding → spring twist → barrel torque → train load / transmission → available escapement work → polygon work transfer → scaled Δω → integrated balance θ/ω → escape release → train → hands

The key M6a change is upstream: reserve no longer goes straight into the escapement as its available-work budget.

Arbor winding versus drum release

Crown and ratchet motion now explicitly belong to the barrel-arbor winding side. During running, the click holds that side while reserve consumption accumulates a separate barrel-drum release angle. The visible drum now rotates from that release state.

The current presentation mapping is 8 barrel-drum turns for one nominal full reserve release. That is a reconstruction value, not an ETA service dimension.

Normalized mainspring torque

M6a interprets stored reserve as normalized mainspring twist, then passes that twist through a deliberately simple torque curve: torque falls sharply near the fully unwound state and remains comparatively flatter over most of the usable reserve.

Train load and transmission

Barrel torque is reduced before reaching the escapement:

usable torque = max(0, spring torque − static train load)

escapement drive = normalized usable torque × transmission efficiency

Transmission efficiency92%

M5i now accepts an external work budget

M5i still measures polygon surface-follow distance, contact quality, transfer efficiency, delivered work, rejected work, and the continuous Δω scale. What changed is the source of available work: M6a now supplies post-load train drive instead of M5i using the historical reserve proxy directly.

The historical M5f actuator is still a Δω kick. M5i compensates for that legacy layer by rescaling the kick against the ratio of the external M6a work budget to the old reserve-drive proxy, so the detailed final impulse follows the new post-train power state.

Live M6a diagnostics

The new Barrel → train power path · M6a panel reports mainspring twist, normalized spring torque, arbor winding/held state, cumulative drum release turns, train load, transmission efficiency, escapement work budget, and the current power topology.

Typical topology states are ARBOR WINDING · DRUM HELD, ARBOR HELD · DRUM RELEASING, ARBOR WINDING + DRUM RELEASING, and UNWOUND.

What remains normalized

  • spring twist is still identified with normalized reserve rather than derived from geometric arbor/drum relative angle;
  • barrel torque is dimensionless rather than N·mm;
  • train load is presently a fixed normalized load rather than state-dependent tooth/jewel friction;
  • the 8-turn drum mapping is a presentation assumption;
  • M5i work remains normalized work units rather than joules;
  • balance inertia, hairspring stiffness, pallet friction, oil-film loss, and actual train efficiency remain uncalibrated.

Why M6a matters

There are now distinct first-class states for user winding input, arbor motion, stored spring twist, spring torque, drum release, train load, transmission loss, escapement-side work, geometric transfer, and oscillator state. Later measured values can replace individual assumptions without collapsing the whole power path back into one reserve percentage.

Inspection workflow

Assemble the movement, use Winding view while adding reserve, and watch arbor turns / twist / torque increase. Then switch to Escapement, run at 0.1× or 0.25×, and compare M6a escapement drive with M5i available/delivered work and M5f Last impulse Δω. Use 3600× only when you want the drum release and torque falloff to become quickly visible.
