DOCUMENTATION · PROVENANCE · M5H

ETA / Unitas 6497-2

M5h replaces the remaining point/line escapement abstraction with finite reconstructed escape-tooth and pallet-jewel polygons. Lock, impulse following, drop, capture, penetration health, escape release, and impulse admission now refer to the same finite-surface model.

Accuracy contract.

The official reference remains 3 Hz / 21,600 A/h. The polygon shapes and contact thresholds in M5h are educational reconstruction geometry, not ETA manufacturing CAD, service tolerances, or measured contact physics.

Foundation retained

M3 established the reference-derived train and pitch/stack diagnostics. M4 added causal winding, hand setting, reserve, and a power gate. M5a–M5d made Swiss-lever release event-resolved and geometry-constrained. M5e exposed amplitude-dependent rate. M5f replaced the assigned oscillator clock with integrated balance angle θ and angular velocity ω. M5g made geometry admit or deny each escapement impulse.

M5h — finite tooth and pallet surfaces

The historical M5d/M5g solver tracked a tooth tip against calibrated face segments. M5h gives both sides finite area. The escape tooth uses the same tapered/hooked 2D construction as the visible educational escape-wheel primitive, and each calibrated pallet working edge becomes one edge of a finite jewel polygon.

crown → reserve → drive → integrated balance θ/ω → pallet motion → finite tooth/jewel surfaces → lock / impulse / drop / capture → admitted Δω + escape release → train → hands

The same surface model now governs both directions of escapement causality.

Pallet-jewel polygon

M5d already calibrated entry and exit working edges against the reconstructed escape-wheel phase. M5h retains those edges and extends each one back toward the pallet staff to form a finite convex jewel body. Current modeled jewel depth is 0.18 mm.

Separation and overlap

A convex separating-axis test determines whether tooth and jewel polygons overlap. When separated, the solver also measures the nearest finite-surface distance. The UI exposes a signed polygon gap: positive for separation, approximately zero for contact, and negative for overlap.

The current maximum tolerated reconstruction overlap is 0.018 mm. Larger penetration marks the surface solution unhealthy.

Lock

The escape wheel remains locked while the active starting tooth lies inside the current 0.028 mm unlock surface gap relative to its pallet jewel. This replaces the earlier decision based only on a face-center travel distance.

Impulse following

Once lock clears, the solver searches the 12° half-tooth interval for the furthest forward angle where the starting tooth can still follow its jewel inside the current 0.080 mm impulse envelope without excessive polygon penetration. That quasi-static surface-following angle becomes the candidate release.

Drop and capture

If the starting surfaces separate before the target pallet captures the incoming tooth, the solver enters DROP · POLYGON FREE FLIGHT and reports the finite-body gap. The target capture angle is the first angle where the incoming tooth approaches the opposite jewel inside the current 0.030 mm capture gap, refined by a bounded binary search.

Monotonic half-tooth release

Within one beat the escape wheel is never allowed to numerically reverse. Once a greater release angle has been reached, later quasi-static noise cannot unwind that same half-tooth step. The next beat advances the completed half-tooth count and begins a new within-beat solve.

Polygon-admitted impulse

M5h installs its own polygon gate into M5f's impulse-admission hook. A balance center crossing remains only an opportunity. The corresponding entry→exit or exit→entry transition is sampled across the polygon solver; Δω reaches the balance only if a coherent finite-surface impulse interval exists and the penetration constraint remains healthy.

Live M5h diagnostics

The new Polygon contact solver · M5h panel reports current surface event, active surfaces, signed polygon gap, overlap depth, release angle, free-flight drop gap, polygon impulse-gate state, and solver health.

The optional overlay draws the starting jewel polygon, target jewel polygon, active escape-tooth polygon, and nearest contact/separation line directly over the movement.

What M5h still does not claim

  • ETA production tooth or pallet-jewel CAD;
  • exact jewel bevels, edge radii, lock, draw, drop or banking dimensions;
  • rigid-body impact dynamics or contact stress;
  • oil films, sliding friction, rebound or elastic deformation;
  • measured pallet efficiency or physical impulse work;
  • calibrated train torque, balance inertia or hairspring stiffness;
  • factory timing performance.

Inspection workflow

Wind the watch, choose Escapement, assemble the movement, enable Show M5h tooth / jewel polygons, and run at 0.1× or 0.25×. Compare polygon gap, overlap, release angle, drop gap and impulse admission with the M5f θ/ω phase portrait. The older M5d overlay can remain enabled for a direct point/segment-versus-polygon comparison.

Next work

Use finite-surface following distance and available train drive to derive normalized available and delivered impulse work, then make Δω proportional to delivered work instead of a binary admitted/denied gate.

M5j — roller and safety polygons

Bring the roller jewel, fork slot, horns and safety dart into the same finite collision framework so fork engagement and overbanking prevention become geometric checks rather than presentation anatomy.

M6 — shared system mechanics

Separate barrel-arbor winding from barrel-drum release, represent train load/torque transmission more explicitly, and consolidate barrel torque, escapement work, oscillator state and reserve into one shared system model.
