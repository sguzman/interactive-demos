DOCUMENTATION · PROVENANCE · M5C

ETA / Unitas 6497-2

M5c makes the balance amplitude a state rather than a fixed animation. Damping removes amplitude between beats, successful escapement events add reserve-dependent impulse packets, and sufficiently weak amplitude can now fail to unlock the pallet and stall the train.

Accuracy contract.

This is still an educational reconstruction, not manufacturing CAD or a calibrated dynamic simulation. The official ETA rate and reserve remain sourced facts; M5c damping, impulse strength, unlock threshold, restart threshold and torque proxy are normalized reconstruction parameters.

What M3–M5b already established

The reconstruction retains the pitch-constrained train, explicit compound-wheel planes, staffs and jewel spans, endshake diagnostics, causal crown winding, hand-setting mode, stored reserve, event-resolved Swiss-lever release, explicit pallet locking/impulse faces, banking diagnostics, roller/fork safety envelopes, and event-level stepping.

The reference train remains centre 80 teeth; third 60 / 10-leaf pinion; seconds/fourth 120 / 8-leaf pinion; escape 15 / 10-leaf pinion. The 15-tooth escape wheel releases one half-tooth per beat, giving 30 releases per revolution and the existing 5 s/rev reference period at six beats per second.

M5c — normalized oscillator amplitude

The balance now carries a dimensionless amplitude state from 0 to 1. This is intentionally not presented as measured degrees of ETA balance amplitude. The visible balance swing is scaled by that state, so a weakening oscillator visibly swings through a smaller arc.

Damping

Between beat events the oscillator loses amplitude exponentially. The current educational damping coefficient is 0.16 per simulated second. This is a model parameter, not a measured friction or hairspring-loss constant.

Impulse packets

Every successful unlock adds a discrete normalized impulse packet. The current maximum packet coefficient is 0.070. The packet is multiplied by a barrel-drive proxy derived from remaining reserve, so the impulse weakens as the spring approaches the bottom of the modeled usable range.

Barrel-drive proxy

The drive proxy combines a broad decline with a deliberately visible end-of-reserve collapse. The collapse begins around 0.15% normalized reserve and spans roughly another 1.5%. These values exist to make amplitude collapse inspectable; they are not an ETA mainspring torque curve.

Unlock threshold and stall

Unlock threshold0.18 normalized
Restart reserve1.2%
Restart amplitude0.34 normalized

If amplitude falls below the unlock threshold, the movement enters STOPPED · ESCAPEMENT. The power gate reports LOW BALANCE AMPLITUDE, and the remaining mainspring reserve is held rather than silently consumed through a stalled train.

Because the browser demo has no wrist-shake gesture, winding above the restart threshold seeds the normalized oscillator to the restart amplitude so the mechanism can resume. That is an interaction rule, not a statement about exact 6497-2 self-start behavior.

New causal loop.

reserve → barrel-drive proxy → impulse packet → balance amplitude → unlock margin → escapement release → train motion. This is the first pass where reserve affects more than permission to run: it affects the oscillator state that decides whether release is possible.

End-of-reserve behavior

As reserve falls, the drive proxy weakens and impulse packets shrink. Damping then removes more amplitude than weak impulses restore. The balance swing contracts, unlock margin approaches zero, and the escapement can stall with a small residual spring state still present. Rewinding restores a usable oscillator state and reopens the train.

Live diagnostics

The M5c panel exposes normalized balance amplitude, oscillator state, barrel-drive proxy, current impulse packet, unlock margin, successful impulse count and missed-unlock count. The earlier M5b lock-depth, draw, drop, banking and safety diagnostics remain available beside them.

What M5c still does not claim

  • measured ETA balance inertia or hairspring stiffness;
  • actual balance amplitude in degrees;
  • an ETA barrel torque curve or measured pallet efficiency;
  • lubrication, air drag, position-dependent losses or shock behavior;
  • amplitude-dependent rate error or true isochronism;
  • exact self-start threshold or exact reserve-to-impulse mapping.

The nominal cadence is still based on the official 3 Hz rate. M5c makes amplitude and unlock state dynamic, but it does not yet let amplitude perturb rate.

Inspection workflow

Wind the watch, choose the Escapement view, and use 0.1× or 0.25× for slow motion. For discrete inspection, choose 0× paused and use Step next event or Step one beat. To inspect end-of-reserve behavior quickly, use the 3600× reserve-demo scale and watch amplitude / impulse / unlock margin collapse near the bottom of the stored-energy state.
