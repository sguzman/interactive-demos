DOCUMENTATION · PROVENANCE · M3E

ETA / Unitas 6497-2

A movement-first interactive reconstruction of a large hand-wound mechanical watch. M3e makes the compound train read more like an actual wheel-to-pinion system: pitch-derived geometry, explicit axial planes, solved contact phase and optional mesh diagnostics.

Accuracy contract.

The demo is not manufacturing CAD. Important facts and geometry remain classified as official, reference-derived, approximate, or presentational.

M3a — reference timing

The train uses a published 6497 training-tool ratio set: centre 80 teeth, third 60 teeth / 10-leaf pinion, seconds/fourth 120 teeth / 8-leaf pinion, and escape 15 teeth / 10-leaf pinion. At 21,600 A/h this closes to 5 s/rev for the escape wheel, 60 s/rev for the seconds/fourth wheel, 7.5 min/rev for the third wheel, and 1 h/rev for the centre wheel.

M3b — visible tooth and leaf counts

The rendered train uses those same reference counts rather than placeholder counts.

M3c — pitch-derived geometry

For each external mesh the reconstruction derives a nominal module from the current centre distance and tooth/leaf counts using module = 2 × centre_distance / (wheel_teeth + pinion_leaves).

M3d — compound train planes

Large pitch-derived wheel bodies cannot all occupy the same z-plane. M3d assigns explicit bridge-side wheel planes:

Centre wheelz = -0.65 mm
Third wheelz = -1.10 mm
Seconds/fourthz = -1.55 mm
Escape wheelz = -0.65 mm

The third pinion lands in the centre-wheel plane, the seconds/fourth pinion in the third-wheel plane, and the escape pinion in the seconds/fourth-wheel plane.

M3e — pitch-envelope meshing

The constructive gear primitive is intentionally simplified and its authored radius is not itself a strict pitch radius. M3e compensates that visual radius so each simplified tooth envelope actually straddles the solved pitch circle. This removes a visible gap introduced by using pitch math with a presentation-oriented gear primitive.

M3e also solves a static tooth/gap phase through the whole compound chain. The centre wheel is the phase anchor; the third pinion, seconds/fourth pinion and escape pinion are each rotated so their contact phase complements the already-constrained upstream wheel at the line of centres.

Why the big wheels still look separated in projection.

The train is wheel → small coaxial pinion → wheel, not big wheel → big wheel. The new Show pitch mesh guides control displays both pitch circles in each actual mesh plane plus the line of centres. Use the new Train mesh camera preset to inspect that relationship directly.

Balanced camera-axis lighting

The prior pass solved the darkness problem but overshot. M3e keeps the useful brightness range while moving the default back toward the middle.

  • Camera aligned / balanced is now the default.
  • Camera intensity, ambient/fill, environment reflection and exposure are all reduced from M3d.
  • Full bright / diagnostic remains intentionally excessive for difficult geometry.
  • Camera and manual intensities still reach 700, with exposure up to 3.20×.
  • Manual azimuth, elevation and distance controls remain available for raking light.

Simulation presentation

The train can run at 1× real time or 10×, 60× and 300× inspection scales. The balance remains at the documented 3 Hz.
