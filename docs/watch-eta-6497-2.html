DOCUMENTATION · PROVENANCE · M5F

ETA / Unitas 6497-2

M5f turns the balance from an assigned phase clock into an integrated oscillator. Angle and angular velocity now evolve under restoring force, damping, and discrete escapement impulse kicks; recovered oscillator phase then drives the geometry-constrained Swiss lever and the downstream train.

Accuracy contract.

The official reference remains 3 Hz / 21,600 A/h. M5f improves causal architecture, but its damping, impulse gain, visual amplitude normalization, restart state, and amplitude-rate law are educational reconstruction parameters—not measured ETA balance inertia, hairspring stiffness, Q, pallet efficiency, or factory timing data.

Foundation retained from M3–M5e

M3 established the reference-derived train topology, axial wheel planes, staffs, jewels, pitch and clearance diagnostics. M4 made winding, hand-setting and reserve stateful. M5a–M5d made Swiss-lever release event-resolved and then geometry-constrained using reconstructed pallet faces and tooth/contact distances. M5e exposed amplitude-dependent rate explicitly instead of assuming perfect timekeeping at every usable amplitude.

M5f — explicit oscillator state

The balance now owns two primary states:

Angular positionθ
Angular velocityω
Nominal natural frequency2π · 3 rad/s

Those values are advanced numerically rather than reconstructed from a preassigned phase clock.

Restoring and damping terms

The educational balance/hairspring equation is approximately:

θ¨ = −ωₙ²θ − 2ζωₙω

The first term is the hairspring-like restoring acceleration; the second is velocity-dependent damping. M5f currently uses a normalized damping ratio around 0.006. No claim is made that this equals the physical 6497-2 balance/hairspring damping coefficient.

Escapement impulse is now Δω

Successful impulse no longer directly adds “amplitude.” Near a balance center crossing, the escapement can add an angular-velocity increment in the direction of motion. The maximum current reconstruction kick is about 0.42 rad/s before reserve and saturation scaling.

Stored reserve still feeds a normalized barrel-drive proxy, so declining reserve reduces the impulse available to sustain the oscillator.

Amplitude emerges from phase space

Normalized balance amplitude is now derived from the current θ/ω state rather than being the oscillator's primary state:

amplitude ∝ √(θ² + (ω/ω₀)²)

The current visual normalization uses about 0.43 rad as the 100% angle scale. That is a presentation normalization, not a sourced physical balance amplitude.

Phase is measured from the oscillator

M5f recovers phase approximately as atan2(ωₙθ, ω), unwraps it continuously, and converts that phase into the time coordinate used by the M5d pallet/contact solver.

This is the architectural reversal that matters: previously phase was assigned first and the balance followed. Now θ and ω evolve first and phase is measured from that state.

Geometry-constrained release remains downstream

M5d still constrains escape-wheel release from reconstructed contact geometry. Current contact targets remain 0.030 mm unlock travel, 0.040 mm capture distance, 0.035 mm nominal contact tolerance, and a 0.006 mm penetration guard.

The recovered oscillator phase drives pallet motion; the contact solver determines the allowed half-tooth escape release; that released angle is converted into train time for the fourth/seconds, third and centre wheels and the hands.

Current causal chain

crown → stored reserve → drive proxy → impulse Δω → integrated balance θ/ω → recovered phase → pallet/contact geometry → escape release → train → hands

M5f is the first milestone where balance phase is genuinely downstream of a dynamical state instead of being a prescribed input.

Live M5f diagnostics

The new panel reports balance angle, angular velocity, normalized amplitude, restoring acceleration, damping acceleration, last impulse Δω, effective frequency, educational seconds/day error, accumulated phase drift, center crossings, successful impulses, and the current integrator mode.

A live phase portrait plots θ against ω/ω₀. Damping tends to spiral the state inward; repeated escapement impulses replenish it.

Detailed ODE integration versus fast-forward

At normal and slow speeds the oscillator is stepped with small numerical substeps, targeting roughly 1/240 s of simulated mechanical time per integration step.

At very large diagnostic time scales, explicitly integrating thousands of 3 Hz cycles per rendered browser frame would be wasteful and could make the UI unusable. M5f therefore switches to a clearly labeled FAST-FORWARD ENVELOPE approximation that advances amplitude and phase in aggregate, then reconstructs θ and ω. The UI tells you when that mode is active.

M5e isochronism retained as a transparent modifier

The earlier amplitude-rate curve remains available as a user-adjustable natural-frequency modifier:

  • 0× — nominal spring / no assumed amplitude-rate coupling;
  • 1× — educational curve;
  • 5× — diagnostic exaggeration;
  • 20× — extreme inspection.

At 1× the current reconstruction curve uses a reference amplitude around 0.74, a low-amplitude endpoint near −120 s/day, and a high-amplitude endpoint near +12 s/day. Those remain explicit assumptions rather than measured ETA data.

Power-system ownership

M5f now owns the escapement power gate. The M4c reserve system exposes its original reserve-consuming advance path so the M5f oscillator can decide whether motion is physically permitted, hold reserve on an oscillator/contact stall, and then call the original reserve accounting only when the mechanism is allowed to run.

What M5f still does not claim

  • measured ETA balance inertia or hairspring stiffness;
  • actual damping/Q or escapement efficiency;
  • real impulse torque, contact duration or oil friction;
  • physical balance amplitude in degrees;
  • regulator-pin geometry, poise error, beat error or positional timing;
  • temperature effects or shock response;
  • calibrated barrel torque-to-oscillator dynamics;
  • factory timing performance.

Inspection workflow

Wind the watch, choose the Escapement view, and use 0.1×, 0.25×, 0.5× or 1× to inspect the actual θ/ω integration. Watch restoring acceleration, damping and Δω while the phase portrait loops. Enable the M5d solver overlay to compare oscillator-driven pallet phase with contact geometry. Use 300× or 3600× for reserve/run-down demonstrations; the integrator readout will explicitly switch to fast-forward envelope mode.

Next work

M5g — geometry-admitted impulse

Make the M5d impulse-contact state itself admit or reject each M5f Δω packet, so an eligible center crossing is no longer sufficient by itself. Expose delivered impulse work and missed-contact diagnostics.

M5h — deeper polygonal contact

Replace tooth-tip/segment distance with reconstructed tooth and pallet-face polygon intersection, derive lock/drop from those surfaces, and bring roller-jewel/fork-slot safety checks into the same contact framework.

M6 — shared system simulation

Separate barrel-arbor winding from barrel-drum release, improve train force transmission, and consolidate barrel torque, escapement impulse, oscillator state and reserve into one system model.
