# DMG-01 geometry reference source

The public Game Boy geometry is grounded in the documented open-source reconstruction at
`tiansongyu/open-console-cad`, pinned at commit
`55081da3b4864aba36082644f9a3c5cedf1061c8`.

Upstream Game Boy asset metadata:

- 410 components
- 660,428 triangles
- 90 × 148 × 32 mm nominal envelope
- 47 × 43 mm display window
- SHA-256 `9aed0c26e836442ffce065f3607316df7f6d55742b708b9db2394e09e8d99beb`
- original project content licensed MIT

This is a strong P4 external CAD reconstruction, not Nintendo factory CAD.
