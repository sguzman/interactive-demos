# IBM Selectric 721 — interactive engineering specimen

Public constructive projection of `specimen:ibm-selectric-721`.

This is a source-aware mechanical reconstruction of an original IBM Selectric Model 721 representative profile:

- 7X1 width class;
- 8.5-inch writing line;
- 12 CPI representative pitch;
- fabric ribbon;
- later/new-style Series 72 representative print mechanism;
- gearless tilt;
- NRB/S backspace branch;
- local Level-2 carrier-support geometry.

## Provenance boundary

Exact source-backed dimensions are retained where available.

Unresolved hidden coordinates and sections use explicit P4 constructive reconstruction. The visible browser model is not IBM production CAD.

The temporary browser key-to-typeball-slot map is P5 presentation. It assigns 44 base tilt/rotate positions and pairs them across the two hemispheres, so lower/upper letter pairs preserve the same tilt/rotate coordinates and request the independent 180-degree shift mechanism when needed. The six public code bits are a synthetic downstream selector-request vector coherent with the modeled T1/T2/R1/R2/R2A/five-unit inputs; they are not claimed to be the literal factory interposer-lug pattern. For the five ordinary T/R channels the visible keyboard mechanism explicitly inverts that vector at the source-backed selector-bail -> latch-exclusion boundary. The sixth public bit remains a P5 continuation for the browser state machine: its exact mapping onto the sixth ordinary selector-bail/special-application channel is unresolved and is not asserted as factory five-unit geometry. This still does not claim one specific factory typeball character layout.
