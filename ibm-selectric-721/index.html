Power note: the operational shaft receives a deliberately slowed P5 continuous-motion presentation while powered. Power-off blocks ordinary character and powered operational actions rather than merely freezing the display.

Cover note: the hinged service-cover motion is a P5 presentation path kept separate from exploded inspection and from the live mechanical state. Opening it exposes the carrier/type-element region without moving the frame.

Paper-path note: paper release rotates a common actuating shaft and moves the front and rear feed-roll banks together into a latched release state. The paper bail is independently modeled as a two-stable-state toggle with two laterally adjustable rollers. Copy control has five discrete settings: setting 1 is IBM's forward/normal reference, while settings 2–5 move the platen plus the entire paper-feed carriage rearward using explicitly P5 display offsets because the factory offsets are unresolved. The line-spacing selector changes an index operation from one to two teeth of the active 27-tooth representative ratchet. Physical sheet advance now follows P2 platen arc length from the 18.1864 mm radius and ratchet angle while the feed rolls are engaged; the detailed pawl-stroke amplitude remains P5 while the one-vs-two-tooth function is source-backed. Platen variable is a separate coupling state: when free, manual platen rotation no longer moves the ratchet.

Horizontal-motion note: the IBM 1124073 tab-stop bar is now live: startup uses a clearly labeled P5 every-eight-column stop pattern, but stops can be set or cleared at the current carrier column and Tab searches the active stop set before falling through to the right margin. Tab propulsion remains mainspring-driven with the operational-shaft governor modeled as non-propulsive. The IBM 1164743 margin-rack stops are movable on the same 12-CPI pitch: the public margin button toggles a 12-column inset demonstration, carrier return terminates at the live left stop, and ordinary rightward motion is bounded by the live right stop with a modeled line-lock state. A spacebar request made while a character cycle still owns the shared escapement trigger is stored behind the modeled filter-shaft interlock and released after the character's escapement completes. Exact tab set/clear linkage and margin-release actuator detail remain unresolved.

Ribbon note: the new-style fabric ribbon exposes the four documented print states (stencil / low / middle / high), plus a distinct threading/load pose above the high print position. Stencil centers the feed pawl/checking state and suppresses ribbon feed. Ordinary fabric feed is bidirectional and auto-reverses through an animated source-ordered sequence: the exhausted-side trigger moves, the feed/reverse plate pivots, and the pawl/checking state transfers to the opposite ratchet before direction changes. Exact lift/load heights, total ribbon length and ratchet geometry remain unresolved, so the relative lift heights and compressed spool-end threshold are explicitly P5 presentation values rather than factory dimensions.

Selection note: keyboard characters use a deterministic P5 assignment to 44 base tilt/rotate positions paired across the two shift hemispheres. Lower/upper letter pairs therefore share tilt/rotate coordinates and differ by the independent 180° shift state. The six displayed code bits are the modeled T1, T2, R1, R2, R2A and five-unit selection inputs; this is still not a claim about one exact factory typeball character layout.

Exact factory geometry is not claimed for unresolved hidden sections. P4 parts preserve the active branch, known dimensions, service topology and mechanical relationships while the reconstruction is refined.
